**SAFAR N MANZIL** is a dedicated travel assistance and relocation service portal engineered to solve real-world challenges for professionals, families, and travelers moving between India (Telangana & Hyderabad) and the Gulf countries (Saudi Arabia, UAE, Qatar, Kuwait, Bahrain, Oman).

---

## 🌍 Service Offerings

- **Airport & Travel Assistance:** Guidance on travel requirements, luggage policies, and flight bookings.
- **Accommodation & Housing:** Reliable flat and room search assistance in Gulf metropolitan centers.
- **Visa & Document Guidance:** Clear checklists for employment visas, family permits, and embassy attestations.
- **Community & Local Support:** Emergency helpline numbers and local community networks for new arrivals.

---

## 🚀 How to Run Locally

```bash
# 1. Clone repository
git clone https://github.com/MuhammadMinhaj229/safar.git
cd safar

# 2. Serve static files with any local HTTP server
npx serve .
# or python:
# python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000).

---

## 🌐 How to Deploy to Vercel

1. Push to GitHub.
2. Import `safar` into Vercel.
3. Framework Preset: **Other**.
4. Output Directory: `./` (Root).
5. Click **Deploy**.
